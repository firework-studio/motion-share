# 二维码小树

一个网页小工具：输入一个链接，二维码的地面上就会长出一棵体素小树。点一下树，镜头转到正上方，树叶垒成方块，整个画面变成一张能扫的二维码；再点一下，又变回小树。

- 春、夏、秋、冬四季：樱花与晨光、正午的太阳和蝴蝶、秋雨、雪落在常青树上。
- 每季 5 种颜色，换颜色时淡入淡出。
- 一键下载二维码图片（正上方视角，可直接扫）。

纯网页，用 [three.js](https://threejs.org) 绘制，不需要安装任何东西。

成片预览：[preview.mp4](preview.mp4)

## 运行

浏览器打开本地文件时，模块脚本会被拦截，所以需要起一个本地服务。在本文件夹中执行任一条：

```bash
python3 -m http.server 8000     # 然后打开 http://localhost:8000
npx serve .                     # 或者用 Node.js
```

地址后面可以带参数：`?season=winter` 指定季节（`spring`、`summer`、`autumn`、`winter`），`?u=https://你的链接` 指定链接。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面和下方的控制面板 |
| `main.js` | 全部场景：地面、树、四季、天气、转场和下载 |

## 常改的地方

都在 `main.js` 里：

| 想改什么 | 改哪里 |
| --- | --- |
| 默认链接 | `DEFAULT_URL` |
| 每季的颜色、草色、落叶数量、雨雪 | `SEASONS` |
| 太阳的位置和光线强弱 | `LIGHTS` |
| 树的造型（几层枝叶、伸多远） | `PADS` |
| 树干的弯曲 | `C0`–`C3` |
| 转场的快慢 | `TURN_MS` |
| 二维码方块的最深颜色（太浅会扫不出） | `TILE_L` |

## 几个做法

- **树和二维码是同一个场景**：二维码的每个深色格子上方，都有一摞和树叶同色的方块。斜着看，它们和树叶一起组成一棵树；转到正上方，方块的顶面正好拼成二维码。
- **好看又能扫**：容错等级用最高的 H；方块的颜色会自动加深，直到亮度足够低，扫码器分得清深浅。
- **转场**：镜头一边转，方块一边按树的形状从小到大垒起来；快转到正上方时，叶子缩小散开，只剩方块。
- **四季**：每季有自己的光。春夏有太阳，转动时树影跟着转；秋天下雨、冬天下雪，都是阴天的柔光。
