# 光标群搭网页

一个网页动效：页面先被一道扫描线擦成黑底，一群彩色光标飞出来，像设计师在软件里搭稿一样，把整个网页一层层搭回来。

- 拖出选框，四角有控制点，下面挂着蓝色尺寸标签，顶部有像素标尺和参考线。
- 色块边拖边填满；图片先是灰色占位块，再在原位透出来；文字先拉框，再点进去逐字打出来；大标题先打小字，再拖角放大到原位。
- 一行几张图会复制一行往下拖；视频要光标点一下播放才动起来。
- 搭完一屏才往下滚；搭完全部，光标依次飞回页脚的标志。
- 底部控制条可以重播、调速（1×／2×／3×）、直接跳到搭好的页面；`Alt + Shift + S` 也能重新搭一遍。

纯网页，不依赖任何库，不需要安装。

## 运行

页面里有视频，直接双击打开时有些浏览器会拦截，所以建议起一个本地服务。在本文件夹中执行任一条：

```bash
python3 -m http.server 8000     # 然后打开 http://localhost:8000
npx serve .                     # 或者用 Node.js
```

## 用在自己的页面上

把 `swarm.css` 和 `swarm.js` 放进你的页面，`swarm.js` 放在 `</body>` 前，然后给想被"搭"出来的元素加上 `data-b` 属性：

```html
<link rel="stylesheet" href="swarm.css" />
...
<div class="card" data-b="block">            <!-- 色块、容器：拖框时一起长出来 -->
  <img src="cover.jpg" data-b="image" />      <!-- 图片：先灰块，再透出来 -->
  <h2 data-b="text">标题</h2>                 <!-- 文字：拉框后逐字打出 -->
</div>
<script src="swarm.js"></script>
```

| 属性 | 作用 |
| --- | --- |
| `data-b="block"` | 色块、卡片、按钮。容器先搭，里面的东西后搭 |
| `data-b="image"` | 图片或视频。视频会出现播放按钮，由光标点击播放 |
| `data-b="text"` | 文字。字号 30px 以上的标题会先打小字再拉大 |
| `data-b="tiles"` | 大背景。切成大小不一的块，分块铺回 |
| `data-count="40" data-suffix="+"` | 数字从 0 跳到 40，再加后缀 |
| `data-together`（加在区块上） | 区块里的图片一组出场：先画第一行，复制一行往下拖，再依次点播放 |

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 示例页面（Firework 工作室的主页） |
| `swarm.js` | 全部搭建逻辑：光标、选框、打字、复制、滚动、结尾 |
| `swarm.css` | 光标、选框、尺寸标签、标尺、控制条的样式 |
| `prism.js` | 首屏的棱镜光带（WebGL），从头像向两侧流出 |
| `assets/` | 头像、标志、示例图和短片、字体 |

## 常改的地方

都在 `swarm.js` 顶部：

| 想改什么 | 改哪里 |
| --- | --- |
| 光标颜色 | `COLORS` |
| 一开始几个光标、最多几个、多久加一个 | `N0`、`NMAX`、`JOIN_EVERY` |
| 拖框、停留、发放的快慢 | `DRAW`、`HOLD`、`RELEASE` |
| 同时最多几个光标在干活 | `MAX_ACTIVE` |
| 开场擦除、扫描、点亮的时长 | `WIPE`、`SCAN`、`IGNITE` |

## 几个做法

- **主次有序**：每一屏按"背景 → 大块 → 标题和图片 → 小字"分层，层内按阅读顺序发给最近的空闲光标；容器的框画好后才轮到里面的内容，叠在图片上的文字等图片出来再写。
- **动作有因果**：每个画面变化都对应一个鼠标动作——按下拖框、松开定住、点进文字框、点播放；没活的光标停在原地变淡，不乱飘。
- **布局不跳**：打字时文字框锁住最终宽高，居中的容器不会跟着变窄变宽。
- **不会卡住**：有一个看门狗，所有光标闲着超过 2.5 秒就推动下一步。
