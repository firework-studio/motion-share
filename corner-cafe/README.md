# 城市小店 01 · 咖啡窗

一条下班路上的街角：天慢慢黑下来，店员按下开关，吊灯、招牌、取餐窗依次亮起，光落到人行道上；一个拿着咖啡的路人正好走过窗前，再经过路灯，影子在地上拉长，然后走远。夜深后楼上的灯一盏盏熄掉，店员关店，天亮了，下一圈接着来。

全部是线稿 SVG，放多大都清晰。点一下路人，他会停下来，把咖啡举向你。

## 壁纸

在 `wallpapers/` 里，可以直接保存使用：

| 文件 | 内容 |
| --- | --- |
| `phone-1080x1920.png` | 手机静态壁纸，上方给锁屏时钟留了空 |
| `desktop-1920x1080.png` | 电脑静态壁纸，左侧给桌面图标留了空 |
| `phone-loop-1080x1920.mp4` | 手机竖版循环视频，约 21 秒一圈，首尾无缝 |
| `desktop-loop-1920x1080.mp4` | 电脑横版循环视频，约 29 秒一圈，首尾无缝 |
| `iphone-live-3s-1080x1920.mp4` | 给 iPhone 实况照片用的 3 秒亮灯：每次点亮屏幕，街角的灯亮一次 |

循环视频是视频素材，不是系统自带的“动态壁纸”安装包，能不能设成会动的壁纸要看设备：

| 设备 | 怎么用 |
| --- | --- |
| 安卓手机 | 多数机型的主题或壁纸设置里可以把视频设成动态壁纸 |
| iPhone | 用 intoLive 一类的 App 把 `iphone-live-3s` 转成实况照片，设成锁屏；按住或点亮屏幕时会播放亮灯 |
| Mac | 用 Plash 等工具；Plash 也能直接把下面的网页版设成壁纸 |
| Windows | 用 Lively Wallpaper（免费，也能直接用网页版）或 Wallpaper Engine |

做不到的话，用上面的静态图也很好看。

## 网页版

网页版会实时绘制，可以互动，也能改店名。需要 Node.js 18 以上。在本文件夹中执行：

```bash
npm install
npm run dev        # 打开终端里显示的地址
```

地址后面可以带参数：

| 参数 | 作用 |
| --- | --- |
| `?name=今晚见` | 换店名，2–5 个字，竖排自动排版 |
| `?frame=34` / `916` / `169` | 换成 3:4、9:16、16:9 的取景；默认是 4:3 |
| `?tau=0.86` | 停在某个时刻：0.66 是下午，0.86 是深夜 |
| `?lightT=0.9` | 停在亮灯过程中的某一刻（店员按下开关后的秒数） |

## 文件

| 文件 | 内容 |
| --- | --- |
| `cafe.ts` | 整个场景：建筑、店员、路人、昼夜、亮灯与关灯的顺序、路灯和影子 |
| `design/` | 植物（天竺葵、常春藤、虎皮兰）和受光面的 SVG 片段 |
| `lib/` | 线稿动画基础库 [line-art-animation](https://github.com/JDhruv14/line-art-animation)：线条、步态、弹簧与摆动、昼夜配色 |
| `index.html` | 页面 |

## 常改的地方

| 想改什么 | 改哪里 |
| --- | --- |
| 店名 | 地址参数 `?name=`，或 `cafe.ts` 里 `setName(...)` 的默认值 |
| 主色 | `cafe.ts` 顶部的 `TERRA`（陶红，遮阳棚和外套）和 `TEAL`（青绿，帆布袋） |
| 一圈多长 | `cafe.ts` 里的 `DUSK`、`NIGHT_END`、`CYCLE`；路人走到窗前的那一刻和亮灯最亮的那一刻是对齐的，改的时候一起改 |
| 亮灯的先后 | `cafe.ts` 里 “the beats” 那几行：吊灯、招牌、取餐窗、门和路灯、楼上两扇窗 |
