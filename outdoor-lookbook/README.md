# 服装品牌 Lookbook 购物页

一个可以直接改成自己品牌的服装 Lookbook 页面：六套造型排成一圈 3D 轮播，点开一套能看到身上每件单品，选尺码加入购物车，整套还能打折购买。

在线体验：https://firework-studio.github.io/motion-share/outdoor-lookbook/

- **3D 走秀轮播**：中间的造型清晰，两侧依次缩小、上移、变虚；自动播放，可点箭头、点编号、拖动或用键盘左右键切换；每次切换有一道光从模特身上扫过。
- **点开看单品**：身上 1–4 号标记点对应右侧单品，悬停高亮，点 + 选尺码即加入购物车。
- **拖到身上试穿**：点开「雪山」后，从左侧衣架把风衣拖到她身上就能换上，右侧单品和价格跟着变；再拖回原来那件即还原。
- **整套购买**：显示原价与折后价，一键加入全部单品。
- **中英文切换**：右上角「EN / 中」，地址后加 `?lang=en` 直接打开英文版。
- **手机适配**：手机上轮播在上、单品列表在下。

纯网页，不依赖任何库，不需要安装。

## 运行

在本文件夹中执行任一条，然后打开 http://localhost:8000：

```bash
python3 -m http.server 8000
npx serve .
```

## 换成自己的品牌

只需要改 `data.js`，其他文件不用动：

| 想改什么 | 改哪里 |
| --- | --- |
| 品牌名 | `brand`；左上角标志换掉 `assets/logo.svg` |
| 货币、整套折扣 | `currency`、`bundleOff`（0.1 即减 10%） |
| 默认语言、界面文字 | `lang`、`text.zh` / `text.en` |
| 每套造型 | `looks` 里每一项：`title` 名称、`model` 模特图、`pins` 标记点位置、`items` 单品 |
| 每件单品 | `cat` 分类、`name` 名称、`price` 价格、`img` 商品图、`sizes` 尺码（空格分隔） |
| 试穿 | 某套造型的 `tryOn`：可换上的其他造型的外套，及她穿上这件的照片；`base` 为脱掉外套的照片（可选，有它换装更干净），衣架上的外套图用 `cut`（去背景） |

### 图片要求

| 图片 | 要求 |
| --- | --- |
| 模特图 | 去背景的全身照（透明底），2:3，脚靠近底边；六套的人物大小、站位尽量一致 |
| 商品图 | 1:1，浅灰或白底 |
| 试穿图 | 和原模特图同一个人、同一姿势、同样大小和位置，只换外套 |

标记点 `pins` 的数字是该单品在模特图上的位置，以图片宽高的百分比计，从左、从上量起。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构 |
| `data.js` | 品牌、造型、单品、界面文字 |
| `lookbook.js` | 轮播、标记点、单品与购物车、试穿、鼠标跟随、语言切换 |
| `lookbook.css` | 样式与手机适配 |
| `assets/` | 标志、模特图、商品图 |
