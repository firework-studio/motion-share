# 设计需求：<片名>

这是一条“现场演示”教程片：每句旁白都是一个正在发生的操作。画面用本套件的物件和动作，不要重新发明一套。

- 旁白稿：`docs/旁白稿模板.md`
- 逐句时间：`python3 words.py`（成片时间 = 配音时间 + 0.4 秒）
- 参考视频的拆解：`docs/逐帧拆解需求.md`

## 可用物件（`assets/kit/live-kit.css` 里的类名）

光标 `.cursor`、点击环 `.click`、步骤数字 `.step`、盖章字 `.stamp`、一行字幕 `.subtitle`、输入条 `.input-only`、对话框 `.dialog` / `.chat`、视频文件 `.file-object`、文件图标 `.asset-file`、帧条 `.frame-strip`、数据表 `.depth-grid`、代码编辑器 `.code-editor`、照片 `.photo`、提示词卡 `.prompt-input`、页面窗口 `.solid.page-object`、动图卡 `.gif-card`、文件夹 `.fold-back` + `.fold-front`、数字方块 `.number-tile`

## 可用动作（`assets/kit/live-kit.js`）

落下（8 帧回弹）、盖章（6 帧）、光标沿路径移动与点击、拖拽、打字、沿路径划线、文件落进文件夹、步骤数字弹出后缩到角标、字幕逐词出现、片尾落款

## 要求

1. 每句至少一个可见操作，平均 0.5–1 秒一个动作，动作有因果：点了才弹出，拖进去才有结果。
2. 东西落地、盖章时，周围要有回应：容器轻跳、主持人顺势一沉、一点烟尘或短射线。一次只做一件事，做完就收。
3. 同一时刻在场的物件不要互相压住，刻意“拖进去”的除外。
4. 界面画成通用样式，不放别人的品牌；只用自己的素材。

## 交付

每段 2–4 张关键帧，和一张逐个动作的时间表：触发字、起止秒、操作与结果、缓动。
