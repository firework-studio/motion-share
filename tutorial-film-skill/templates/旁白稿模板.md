# 旁白稿：<片名>

口吻是“我带你做”。先说缺口和承诺，再给路线（一共几步），之后每一句回答上一句引出的疑问；全程只用一个例子。约 60 秒、280 字左右。

## 节奏

| 段 | 时长 | 要说的 |
| --- | --- | --- |
| 钩子 | 0–5 秒 | 大家都在做 X，却没人告诉你怎么做 |
| 承诺 | 5–9 秒 | 所以我全拆给你看，一共 N 步 |
| 每一步 | 每步 5–10 秒 | 第几步，做什么；下一句说结果或理由 |
| 最好玩的一步 | 10–15 秒 | 用“现在，最好玩的来了”提一下气 |
| 收尾 | 5–8 秒 | 这就是整个流程；想要什么，私信我「关键词」 |

## 检查

- 每句都有一个看得见的操作。
- 没有空话（“非常简单”“超级好用”）；每句都有具体的东西：一个按钮、一个文件、一个数字。
- 提到的工具给出替代（例如 Claude Code / Cursor / Trae）。
