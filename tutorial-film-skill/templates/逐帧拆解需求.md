# 逐帧拆解需求：<参考视频名>

把参考视频交给能看视频的 AI（或自己用 ffmpeg 抽帧），按下面的格式逐段量出来。拆得越细，复刻越像。

## 输入

- 参考视频：`<路径>`（分辨率、帧率、时长）
- 要拆的段：第 <n> 段，<起> – <止> 秒

## 先量边界

- 本段第一帧和最后一帧（帧号，不要按秒估），段内有没有硬切。

## 逐个动作表

| 动作 / 物件 | 起止与到位帧 | 看到的样子 | 位置、大小、角度、层级 | 运动和缓动 | 对应旁白 |
| --- | --- | --- | --- | --- | --- |
|  |  |  | (x, y, 宽, 高)，1080×1920 坐标 |  |  |

位置统一写左上角和宽高；拿不准的标“估”，量出来的标“测”。

## 素材清单

| 素材 | 外观 | 怎么做（CSS / SVG / 需要生成的图） |
| --- | --- | --- |

## 不要

- 不要把参考视频里别人的人物、截图、品牌拿来当成片素材，只作为测量依据。
- 不要把“看起来差不多”写成测得的数值。
