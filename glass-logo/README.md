# 液态玻璃图标

一个网页小工具：一滴水珠在黑底上胀开，变成一块厚厚的玻璃圆角方块，边缘带彩色折射，中间嵌着 logo。动画播完停在方块上，移动鼠标可以转动光线。

- 四种配色：彩虹、冰蓝、玫瑰、香槟金。
- 内置五个 logo：Firework、音符、星芒、爱心、闪电。
- 把任意图片拖进页面就能换成自己的 logo；点击画面重播。

纯网页，用 WebGL 绘制，不需要安装任何东西。

成片预览：[preview.mp4](preview.mp4)

## 运行

浏览器打开本地文件时，图片和脚本会被拦截，所以需要起一个本地服务。在本文件夹中执行任一条：

```bash
python3 -m http.server 8000     # 然后打开 http://localhost:8000
npx serve .                     # 或者用 Node.js
```

地址后面可以带参数 `?logo=图片地址` 直接指定 logo。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面和下方的控制条：配色、内置 logo |
| `main.js` | 全部绘制：logo 转成剪影、玻璃厚度、折射与色散、动画节奏 |
| `logos/` | 内置的五个 logo（白色线稿 SVG） |

## 常改的地方

| 想改什么 | 改哪里 |
| --- | --- |
| 配色 | `index.html` 里的 `SETS`：`tint` 玻璃染色，`bg` 背景色 |
| 内置 logo | 换掉 `logos/` 里的 SVG，或改 `index.html` 里的 `LOGOS` |
| 默认 logo | `main.js` 里 `useLogo(...)` 的默认路径 |
| 胀开的节奏 | `main.js` 里的 `WIDTH`（方块随时间变宽）和 `LENS`（透镜大小） |

logo 用白色、透明底的图片效果最好，线条或剪影都可以。
